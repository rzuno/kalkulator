## Future releases

A software release will identify its version and immutable tag/commit, selected source and required dependencies, installation and reproduction instructions, tests actually performed, supported inputs and outputs, assumptions, limitations, and licensing terms. Released snapshots will be preserved, and changes will be described in subsequent versions.

Numerical or symbolic calculations are not presented as formal proofs. Any connection to a Lean theorem will link to the exact verified statement, assumptions, and proof package version. Any connection to a paper will identify its published edition.

The catalogue will list actual software releases when they exist. No software release tags or GitHub Releases exist yet. Development material is maintained separately until selected for release.
